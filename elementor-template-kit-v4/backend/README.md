# بک‌اند کیت اسدزاده (PHP)

دو فایل اصلی:

| فایل | وظیفه |
|---|---|
| `asadzadeh-kit-shortcodes.php` | پیاده‌سازی شورتکدهای `[az_*]` که دادهٔ واقعی را می‌خوانند |
| `asadzadeh-kit-cpt-acf.php` | ثبت CPTها، متای کلاس حضوری و گروه‌های فیلد ACF |

بدون این فایل‌ها، قالب‌هایی که وضعیت **NEEDS CUSTOM BACKEND** دارند
(داشبورد، دوره‌های من، تکالیف، گواهی‌ها، سفارش‌ها، استعلام گواهی،
ظرفیت کلاس حضوری و غیره) داده‌ای برای نمایش نخواهند داشت.

## نصب

ساده‌ترین روش: هر دو فایل را در `wp-content/mu-plugins/` قرار دهید
(اگر پوشه وجود ندارد بسازید). mu-plugins بدون نیاز به فعال‌سازی بارگذاری می‌شود.

روش دوم: یک پوشهٔ افزونه بسازید، هر دو فایل را داخل آن بگذارید و به فایل اول
یک هدر افزونه اضافه کنید:

```php
<?php
/**
 * Plugin Name: Asadzadeh Kit Backend
 * Description: Shortcodes, CPTs and ACF fields for the Asadzadeh Elementor kit.
 * Version: 5.0.0
 */
```

سپس از پیشخوان فعال کنید.

## نکات امنیتی (مهم)

- همهٔ فرم‌ها با nonce محافظت شده‌اند (`wp_verify_nonce`).
- همه‌جا خروجی escape و ورودی sanitize شده است.
- مشاهدهٔ سفارش و گواهی با بررسی مالکیت انجام می‌شود؛ شناسهٔ ارسالی از URL هرگز
  اعتماد نمی‌شود.
- استعلام عمومی گواهی با transient محدود شده (۲۰ درخواست در ۱۰ دقیقه برای هر IP)
  و تنها نام دوره، تاریخ و شناسه را نشان می‌دهد — اطلاعات شخصی دارنده نمایش داده نمی‌شود.
- بارگذاری تکلیف نوع و حجم فایل را بررسی می‌کند (حداکثر ۲۰ مگابایت).
- هیچ کلید، رمز یا نشانی محرمانه‌ای در این فایل‌ها نیست.

## نکات عملیاتی

- `[az_security_sessions]` بدون افزونهٔ مدیریت نشست، **وضعیت خالی صادقانه**
  نمایش می‌دهد. یا آن را پیاده‌سازی کنید یا این بخش را از قالب حذف کنید.
- `[az_workshop_meta field="map"]` به‌صورت عمدی خروجی ندارد؛ نقشه را از طریق
  فیلتر `az_kit_workshop_map` به سرویس دلخواه خود وصل کنید.
- ظرفیت کلاس حضوری = **موجودی محصول ووکامرس**. اگر ترجیح می‌دهید از متای
  `_az_workshop_seats` استفاده کنید، تابع `az_workshop_meta` را تغییر دهید.
- گواهی‌ها از روی دوره‌های تکمیل‌شدهٔ LearnDash استخراج می‌شوند؛ اگر افزونهٔ
  گواهی اختصاصی دارید، از فیلتر `az_kit_user_certificates` استفاده کنید.
- شورتکدهای Digits را حتماً با نسخهٔ نصب‌شده روی سایت تطبیق دهید
  (در `docs/UNRESOLVED-INTEGRATIONS.md` ثبت شده است).

## بررسی نحوی

در این محیط PHP در دسترس نبود، بنابراین `php -l` اجرا نشده است. پیش از انتشار
روی سرور خود این دو فایل را لینت کنید:

```bash
php -l backend/asadzadeh-kit-shortcodes.php
php -l backend/asadzadeh-kit-cpt-acf.php
```
